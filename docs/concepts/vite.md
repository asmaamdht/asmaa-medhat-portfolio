Q1. What is Vite?

Vite is a modern frontend build tool and development server that provides fast startup, Hot Module Replacement (HMR), and optimized production builds.

Q2. Why do developers prefer Vite over Create React App?
- Faster startup.
- Faster HMR.
- Better developer experience.
- Simpler configuration.
- Optimized production build.
  

Q3. What is HMR?

Hot Module Replacement updates only the modified module without reloading the entire page, making development faster and preserving the application state in many cases.


**Note: Vite creates the project template and configures it, while npm installs React and the other dependencies listed in package.json.**
