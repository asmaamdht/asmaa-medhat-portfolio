# Tailwind CSS

## What is Tailwind CSS?

Tailwind CSS is a utility-first CSS framework that allows developers to build custom user interfaces by composing small utility classes directly in HTML or JSX instead of writing traditional CSS.


## Why do we use Tailwind CSS?

* Faster UI development.
* Reduces the need to write custom CSS.
* Encourages consistent design.
* Makes responsive design easier.
* Supports Dark Mode out of the box.
* Generates only the CSS that is actually used.



## What does Utility-First mean?

Utility-First means that each CSS class has a single responsibility.

Example:

```html
<div class="bg-blue-500 text-white p-4 rounded-lg">
```

## Advantages

* Fast development.
* Less custom CSS.
* Consistent design system.
* Easy responsive design.
* Easy Dark Mode support.
* Smaller production CSS.


## Disadvantages

* Long class names.
* Requires learning utility classes.
* HTML/JSX can become crowded with many classes.



# Interview Questions

## What is Tailwind CSS?

Tailwind CSS is a utility-first CSS framework that helps developers build custom user interfaces using small utility classes instead of writing traditional CSS.


## Why is Tailwind called a Utility-First framework?

Because every utility class has a single responsibility, and developers combine multiple utility classes to build custom components.


## Why do developers prefer Tailwind CSS?

* Faster development.
* Less CSS maintenance.
* Consistent design.
* Easy responsive design.
* Easy Dark Mode implementation.


## What is the difference between Tailwind CSS and Bootstrap?

Bootstrap provides pre-built UI components, while Tailwind provides utility classes that allow developers to build fully customized components.


## Is Tailwind CSS a framework or a library?

Tailwind CSS is a CSS framework because it provides a complete styling system, including spacing, colors, typography, responsive breakpoints, and utility classes.
