# Front-End Glossary

## Tool
A software that helps developers build, test, or maintain applications.

Example:
- Vite
- ESLint

---

## Library
A collection of reusable code that developers can call when needed.

Example:
- React
- Axios

---

## Framework
A complete system that provides structure and conventions for building applications.

Example:
- Tailwind CSS
- Angular

---

## Plugin
An extension that adds new functionality to an existing tool or framework.

Example:
- @tailwindcss/vite
